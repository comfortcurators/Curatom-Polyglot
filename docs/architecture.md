# Curatom-Polyglot architecture

The architectural map lives in [`architecture/`](architecture/). Start at
[`architecture/README.md`](architecture/README.md); it is a single page
and it stands on its own.

The remaining files in that directory are for people writing *about*
Curatom rather than *in* it — vocabulary, data model, security model,
deployment topology, and an explicit statement of what Curatom is not.

For what actually works today, see [`../README.md`](../README.md).
For what is deliberately absent, see [`../DEFERRED.md`](../DEFERRED.md).
